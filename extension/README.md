# NoteFlow AI — Google Meet In-Meeting Chrome Extension

Automatic Google Meet detection and 1-click in-meeting Notetaker companion overlay.

---

### How to Install in Google Chrome (30 Seconds)

1. Open Google Chrome and navigate to:
   ```
   chrome://extensions
   ```
2. Toggle on **Developer mode** in the top-right corner.
3. Click the **Load unpacked** button in the top-left corner.
4. Select the `extension/` folder located at:
   ```
   /Users/yogendrasinghdanu/Downloads/Senior Product Designer/Meet Record/extension
   ```

---

### What Happens In Google Meet:

1. When you join any Google Meet call (`https://meet.google.com/xyz`), NoteFlow automatically detects the meeting.
2. A sleek glassmorphic pill appears directly above the bottom control bar:
   ```
   🟢 Meeting detected • Now   [⚡ Start Notetaker]   ✕
   ```
3. Clicking **⚡ Start Notetaker** starts the recording session and live speech-to-text pipeline.
4. When finished, clicking **⏹ Stop & Synthesize** hands off the transcript to NoteFlow AI to generate structured notes, key decisions, and action items.
